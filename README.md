# دفترِ ما — کتاب خاطرات فارسی

کتاب دوصفحه‌ای راست‌چین با عکس‌های چاپی و چسب، ورق‌زدن با دکمه/لمس/کیبورد، پنل مدیریت PHP و ذخیره‌سازی MySQL. در موبایل عکس بالای متن می‌آید؛ در تبلت و دسکتاپ عکس چپ و متن راست است.

## اجرا و ورود

نیازمندی: PHP 8.2 یا جدیدتر، افزونه‌های `mbstring`، `fileinfo`، `session`، `curl` و برای MySQL، `pdo_mysql`.

داخل پوشهٔ پروژه اجرا کن:

```bash
php -S 127.0.0.1:8094 -d upload_max_filesize=25M -d post_max_size=100M
```

- دفتر: http://127.0.0.1:8094/
- پنل: http://127.0.0.1:8094/admin/
- نام کاربری: `admin`
- رمز اولیه، با حروف فارسی: `ادمین`

رمز به‌صورت هش در دادهٔ محافظت‌شده ذخیره شده و از بخش «حساب کاربری» قابل تغییر است. بدون ورود، دسترسی به ویرایش یا تنظیمات وجود ندارد. در بستهٔ بدون حساب، اولین حساب از localhost ساخته می‌شود؛ روی هاست به `setup_key` در config.php نیاز دارد.

## امکانات پنل

- تغییر نام مخاطب، متن شروع، تصویر دفترچه، عنوان‌ها و امضا.
- افزودن، حذف و تغییر ترتیب صفحه‌های خاطره بدون سقف ثابت تعداد؛ تعیین مستقیم شمارهٔ نمایش هر خاطره در دفتر.
- عکس‌ها بدون سقف ثابت تعداد؛ انتخاب صفحهٔ مربوط به هر عکس، توضیح و ترتیب عکس‌ها.
- ویس عمومی یا اختصاصی هر صفحه، و موسیقی پس‌زمینه با تکرار خودکار و تنظیم صدا.
- تصویر آخر، قلب شکسته با مدت پیش‌فرض ۳ ثانیه، متن دعوت دوستانه و دکمه‌های پاسخ.
- متن‌های جداگانهٔ پاپ‌آپ برای قبول و رد دعوت؛ نمایش ۲ ثانیه پس از ثبت موفق پاسخ.
- دیدن پاسخ‌ها و وضعیت ارسال تلگرام، گزارش خودکار بازدید و ورود مدیر با IP و نوع دستگاه، تغییر مشخصات ورود.

محتوا با PHP به HTML تبدیل می‌شود و CSS/JavaScript مشترک آن را نمایش می‌دهند؛ ویرایش متن‌ها و عکس‌ها نیاز به کدنویسی یا بیلد ندارد. در اولین بازدید، پنجره‌ای برای زیادکردن صدای رسانه و خروج از حالت سایلنت نمایش داده می‌شود. «شروع با موسیقی» آهنگ را با همان لمس پخش می‌کند؛ خواندن در سکوت هم ممکن است. بسته‌شدن این پنجره در localStorage همان مرورگر نگه‌داری می‌شود و با تازه‌سازی صفحه دوباره نشان داده نمی‌شود. در مرورگر جدید، حالت خصوصی یا پس از پاک‌کردن دادهٔ سایت دوباره نمایش داده می‌شود. اگر آهنگی بارگذاری نشده باشد، دکمه فقط دفتر را باز می‌کند. موسیقی همچنین از دکمهٔ پخش بالای صفحه قابل کنترل است. سایت نمی‌تواند سایلنت یا صدای رسانهٔ گوشی را دور بزند. پخش ویس، موسیقی و سایر ویس‌ها را متوقف می‌کند.

## MySQL روی هاست

پیش‌نمایش بدون تنظیمات دیتابیس از فایل محافظت‌شده استفاده می‌کند. برای ذخیرهٔ تمام محتوا، پاسخ‌ها، حساب و تنظیمات در MySQL:

1. یک دیتابیس MySQL 8 و کاربر مختص آن بساز.
2. `config.example.php` را به `config.php` کپی و اطلاعات دیتابیس را وارد کن. اگر ساخت حساب اولیه روی هاست لازم است، setup_key را با یک مقدار تصادفی طولانی جایگزین کن.
3. `schema.sql` را در دیتابیس وارد کن، یا از دستور زیر استفاده کن که جدول را نیز می‌سازد.
4. برای انتقال حساب و داده‌های پیش‌نمایش، اجرا کن:

```bash
php migrate.php
```

انتقال، رکوردهای موجود در MySQL را بازنویسی نمی‌کند. داده‌ها در جدول `app_store` با ستون JSON نگهداری می‌شوند؛ پاسخ‌های فرم در رکورد `responses` هستند. وقتی MySQL تنظیم شود، خطای اتصال به ذخیره‌سازی فایل تغییر مسیر نمی‌دهد. در بالای پنل، نوع ذخیره‌سازی دیده می‌شود.

مهاجرت از خط فرمان قابل اجراست؛ از طریق مرورگر اجرا نمی‌شود. اگر SSH نداری، schema.sql را با phpMyAdmin وارد کن و حساب تازه را با setup_key بساز؛ سپس محتوا را از پنل تنظیم کن.

## تلگرام

در «اتصال تلگرام» توکن ربات BotFather و Chat ID را وارد کن. ابتدا در ربات Start بزن. اعلان پاسخ و اعلان بازدید مستقل‌اند. دکمهٔ آزمایش، پیام واقعی ارسال می‌کند. توکن فقط سمت سرور ذخیره می‌شود.

هر دو پاسخ قبول و رد ذخیره می‌شوند. خطای تلگرام مانع ثبت اولیهٔ پاسخ نیست؛ وضعیت ارسال در پنل دیده می‌شود. بازدیدها به‌صورت خودکار ثبت می‌شوند. IP دریافتی از اتصال سرور، زمان، نوع دستگاه، مرورگر، سیستم‌عامل و User-Agent ذخیره می‌شود. اطلاع این ثبت در صفحه و پنجرهٔ شروع نمایش داده می‌شود. اطلاعات برای حدس‌زدن هویت، شمارهٔ تلفن یا موقعیت فرد استفاده نمی‌شود. نوع دقیق دستگاه ممکن است از مرورگر قابل تشخیص نباشد.

ثبت مستقل از تلگرام است و به‌طور پیش‌فرض فعال است. اگر MySQL تنظیم شده باشد لاگ‌ها در رکورد `visits` جدول `app_store` قرار می‌گیرند؛ بدون config.php ذخیرهٔ محلی فعال است و پنل این وضعیت را نشان می‌دهد. توکن ربات و Chat ID باید در پنل ذخیره شوند تا پیام واقعی ارسال شود. وضعیت «اتصال تلگرام تنظیم نشده» با وضعیت خطای ارسال فرق دارد. ورود موفق و ناموفق مدیر نیز در همین بخش با نوع رویداد جداگانه ثبت می‌شود؛ رمز واردشده ذخیره یا ارسال نمی‌شود.

هر نشست جدید مرورگر یک بازدید محسوب می‌شود. تازه‌سازی همان نشست در ۳۰ دقیقه پیام تکراری نمی‌سازد؛ پس این شمارش، شمار افراد یکتا نیست. حداکثر ۱۰۰۰ رویداد و ۱۰۰۰ پاسخ نگهداری می‌شود. IP فقط از REMOTE_ADDR گرفته می‌شود؛ X-Forwarded-For ارسالی کاربران قابل اعتماد نیست. در هاست دارای پراکسی، IP واقعی باید در پیکربندی معتبر وب‌سرور تنظیم شود.

استایل ورود و پنل داخل HTML قرار دارد، تا مسیر نسبی فایل یا کش قدیمی CSS نمایش را خراب نکند. فونت به مسیر نصب سایت ارجاع می‌دهد و اسکریپت پنل نسخهٔ مبتنی بر محتوای فایل دارد.


## استقرار

کل پوشه را روی هاست PHP با HTTPS قرار بده. پوشه‌های data و uploads باید برای PHP قابل نوشتن باشند. در Apache فایل‌های .htaccess حفاظت لازم را اعمال می‌کنند. برای Nginx قواعد زیر را در server block متناسب با مسیر استقرار قرار بده:

```nginx
location ^~ /data/ { deny all; }
location ~ ^/(config.*\.php|schema\.sql|README\.md)$ { deny all; }
location ~ ^/uploads/.*\.(php|phtml|phar|php[0-9])$ { deny all; }
```

فایل config.php و فایل‌های داده/نشست نباید به‌شکل متن از وب قابل دریافت باشند. اسکریپت‌های PHP در پوشه uploads نباید اجرا شوند. برچسب noindex فقط درخواست عدم نمایه‌سازی است؛ کتاب برای هر کسی که لینک آن را داشته باشد قابل مشاهده است.

## محتوای نمونه و آزمون

عکس‌های موجود نمونه‌اند و عکس واقعی شما نیستند. عکس دفترچه، عکس دونفره و روایت خاطره را از پنل جایگزین کن. فایل موسیقی و ویس واقعی همراه بسته نیست.

آزمون انجام‌شده: صحت PHP/JS، ورود با حساب تعیین‌شده، ذخیرهٔ متن و آپلود عکس/ویس/موسیقی روی MySQL 8.4، ارتباط عکس با صفحه، افزودن و جابه‌جایی صفحه، ثبت هر دو پاسخ و جلوگیری از ثبت تکراری، ثبت IP و دستگاه، ورود موفق/ناموفق مدیر، جلوگیری از تکرار بازدید با رفرش، رد CSRF نامعتبر، محافظت فایل حساب، نمایش دسکتاپ و موبایل. ارسال واقعی تلگرام بدون توکن کاربر آزمایش نشده است.

## مسیر پنل و ترتیب صفحه‌ها

آدرس‌های `/admin` و `/admin/index.php` خودکار به `/admin/` هدایت می‌شوند؛ همین رفتار در نصب داخل زیرپوشه نیز برقرار است. بعد از ورود و ذخیره، ریدایرکت به مسیر صریح پنل انجام می‌شود. استایل و اسکریپت پنل همراه HTML ارسال می‌شوند. هر منو لینک مستقیم مانند `/admin/?tab=music#music` دارد و بدون JavaScript نیز آن بخش را نشان می‌دهد.

در «صفحه‌های خاطره»، هر تعداد خاطرهٔ موردنیاز اضافه کن. در «شمارهٔ نمایش در دفتر» عدد مقصد را وارد کن و از کادر خارج شو؛ صفحه همان لحظه جابه‌جا می‌شود. فلش‌های بالا/پایین هم فعال‌اند. شمارهٔ ۱ جلد است؛ خاطره‌ها از شمارهٔ ۲ شروع می‌شوند و دعوت در آخر می‌ماند. شماره، شمارهٔ ورق بازِ کتاب است (هر ورق در دسکتاپ عکس و متن را کنار هم دارد). پس از چیدن صفحه‌ها «ذخیرهٔ دفتر» را بزن. عکس‌ها و ویس هنگام جابه‌جایی به خاطرهٔ خودشان متصل می‌مانند.

محدودیت ثابت تعداد صفحه و عکس برداشته شده است؛ ظرفیت عملی همچنان به حافظه، فضای ذخیره‌سازی و محدودیت حجم درخواست هاست بستگی دارد. متن فرم به‌صورت یک بستهٔ JSON ارسال می‌شود تا max_input_vars در PHP صفحه‌های زیاد را قطع نکند. فرم ناقص ذخیره نمی‌شود و محتوای قبلی محفوظ می‌ماند. تعداد فایل‌هایی که هم‌زمان می‌توان آپلود کرد تابع max_file_uploads سرور است.

آزمون این اصلاح: ریدایرکت ورود بدون اسلش و نصب در زیرپوشه؛ منوی مستقیم بدون JS؛ رویداد کلیک هر ۹ منو؛ افزودن ۲۵ صفحه از منطق رابط؛ ذخیرهٔ ۱۸۰ صفحه؛ جایگاه عددی و فلش‌ها؛ حفظ ارتباط عکس‌ها بعد از مرتب‌سازی؛ جلوگیری از ذخیرهٔ فرم ناقص.
